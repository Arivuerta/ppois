# Лабораторная работа №1

Документация к лабораторной работе: **Машина Поста** и **Вектор 3D**.

## Что внутри

- **PostMachine** — машина Поста: бесконечная лента, каретка, программа команд.
- **PostCommand** — одна команда программы.
- **CommandType** — типы команд (`Mark`, `Unmark`, `Left`, `Right`, `Check`, `Stop`).
- **Vector3D** — вектор в трёхмерном пространстве.

## Вектор 3D
Описать класс для работы с вектором, заданным координатами концов в трёхмерном пространстве. Класс должен реализовывать следующие возможности:

-получение координат концов вектора;
-вычисление длины вектора;
-сложение двух векторов (+, +=);
-вычитание двух векторов (-, -=);
-векторное произведение двух векторов (*, *=);
-произведение вектора на число (*, *=);
-деление вектора на число (/, /=);
-вычисление косинуса угла между двумя векторами;
-операции сравнения двух векторов по длине (>, >=, <, <=).

## Машина Поста
Описать классы, реализующие машину Поста.
